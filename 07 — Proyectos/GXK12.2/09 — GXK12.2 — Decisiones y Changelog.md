## Decisiones e hitos

### Fecha: 2026-10-06 — Hito: Home V0.3 Híbrido como checkpoint visual

Dirección visual de Home cerrada como checkpoint para implementación. Ver [[07 — Proyectos/GXK12.2/07 — GXK12.2 — V0.3 Home|V0.3 Home]].

> Estado al 2026-10-07: **implementación presente en código** (commit `950c566` en `master`), **aprobación / QA visual pendiente**. No es un hito cerrado. Ver [[07 — Proyectos/GXK12.2/00 — Índice|Índice]].

### Fecha: 2026-10-05 — Principio "mucha lógica detrás, poca fricción delante"

**Decisión:** GXK (junto con Proyecto Raíces) adopta "simple por defecto → potente cuando hace falta". La complejidad del modelo, las relaciones, las reglas de negocio y el sistema editorial se resuelven internamente (estructura, defaults, validaciones, automatización); la interfaz muestra primero lo necesario para la tarea actual. Aplica especialmente al Admin.
**Fuente:** doc Linear [Roadmap](https://linear.app/proyecto-raices/document/roadmap-macario-studio-web-base-raices-3beb4db4f227) §13.

### Fecha: 2026-10-05 — V0.2 cerrada y carácter del motion

Visual Rules Lab V0.2 cerrada: suficientemente definida para pasar de exploración a aplicación. No se agregan principios ni experimentos a esta versión. Motion de GXK: tensión / energía / contraste / sorpresa controlada. Ver [[07 — Proyectos/GXK12.2/06 — GXK12.2 — Dirección visual — Reglas aprobadas|Dirección visual]] §15 y §19.

### Fecha: 2026-10-02 — Hito: cierre funcional

La construcción funcional queda cerrada tras los Bloques 1–6. Hubo una auditoría en navegador (desktop y mobile) sobre el commit `01b47ba`, sin errores de página, sin scroll horizontal y sin bugs funcionales nuevos. Los hallazgos restantes son de UX/UI y presentación.

**Decisión:** no agregar funcionalidades nuevas antes de cerrar la etapa visual, salvo bloqueos funcionales reales o integraciones / configuración de producción ya identificadas.
**Próxima etapa definida en ese momento:** UX auditada → dirección visual → aprobación → implementación visual → QA final (hoy, según el flujo visual de MACARIO: Referencias + Figma → Claude Design → Figma → Claude Code → Preview / QA).

### Fecha: 2026-09-29 — Bible como fuente de verdad y roadmap de 6 bloques

**Decisión:** la [[07 — Proyectos/GXK12.2/04 — GXK12.2 — Brand & E-commerce Bible|Brand & E-commerce Bible]] es la fuente de verdad de marca, UX, contenido, producto y reglas de negocio. Obsidian contiene la especificación completa y Linear la ejecución. El producto se organiza en 6 bloques ([[07 — Proyectos/GXK12.2/05 — GXK12.2 — Roadmap de producto|Roadmap]]).
**Principio de diseño:** CLARIDAD → IDENTIDAD → EXPLORACIÓN → EFECTO VISUAL.

### Fecha: 2026-09-25 — Arquitectura compartida y stack

**Decisión:** Storefront Web + Admin Web + Desktop futura con backend / core compartido; Next.js + Supabase; clave privilegiada solo del lado servidor. Ver [[07 — Proyectos/GXK12.2/03 — GXK12.2 — Arquitectura técnica|Arquitectura técnica]] §19.
