### 5.2 Servicios y dependencias

```text
Navegador ─► App Next.js (LAB: 127.0.0.1:3600 · PROD: Vercel)
              ├─► Supabase (LAB: Docker local · PROD: ounjamybbmodfmofiwvg)
              │     ├─ Auth (correos de cuenta: SMTP propio de Supabase/GoTrue)
              │     └─ RPC: create_order, record_payment_result, confirm_order_payment…
              ├─► Mercado Pago API (crear preference; consultar el pago)        [saliente]
              │       └─► webhook ─► /api/mercado-pago/webhook                  [ENTRANTE: necesita URL pública HTTPS]
              ├─► Correo Argentino PAQ.AR (QA/prod) · Andreani (sin implementar) [saliente, post-pago]
              └─► SMTP (emails de pedido; solo EMAIL_ALLOWED_RECIPIENTS fuera de PROD) [saliente]
Dominio + DNS ─► Vercel (dominio propio) · SPF/DKIM/DMARC (SMTP) · URL de webhook productiva · Site URL de Supabase Auth
```

- **Dependencias duras:**
  - El SMTP real necesita dominio con SPF/DKIM/DMARC.
  - El webhook productivo de Mercado Pago necesita dominio (o la URL definitiva de Producción).
  - Los correos de Supabase Auth necesitan SMTP y dominio.
  - El alta de envíos necesita credenciales del transportista y además las decisiones de destino, packaging y despacho.
  - La activación de Mercado Pago necesita la decisión sobre monto y moneda (K7 / PRO-192 §B3).
- **Webhook en LAB:** el laboratorio solo escucha en `127.0.0.1`, así que Mercado Pago no puede notificarlo. Hay dos opciones; elegir es una decisión del responsable (D-03):
  - **(a) Simulación firmada:** reenviar al webhook local una notificación firmada con la clave secreta de prueba, sobre un pago sandbox real. El handler vuelve a consultar el pago real en Mercado Pago. Valida firma, consulta, estados e idempotencia, **pero no** la entrega ni los reintentos de Mercado Pago.
  - **(b) Túnel HTTPS temporal** hacia el laboratorio. Valida la entrega real. Expone la PC del responsable mientras dure, así que **requiere autorización expresa** y se cierra al terminar.
- **Dominio propio y visibilidad:** agregar un dominio propio a Vercel deja Producción **pública** en ese dominio, porque la protección SSO excluye los dominios propios. Conectar el dominio es un paso de lanzamiento y requiere autorización.
