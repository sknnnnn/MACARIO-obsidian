## Siguiente punto — Etapa 4

**Preparar el staging alojado, aislado de producción, con su propio proyecto Supabase y sus propias credenciales/variables.**

Orden recomendado:
1. Definir y confirmar el proyecto Supabase de staging (separado de producción).
2. Configurar variables de entorno y service-role exclusivo para ese entorno, sin reutilizar secretos de producción.
3. Conectar el Preview de la rama de beta al Supabase aislado.
4. Verificar autenticación/sesión Admin y flujo Admin → publicación → Preview.
5. Después habilitar las pruebas de integración: Mercado Pago sandbox/webhook, email transaccional y envíos, según credenciales disponibles.

**Bloqueo conocido:** para emails transaccionales sigue haciendo falta dominio/SMTP bajo control del responsable de GXK o una excepción explícita. No se debe intentar resolverlo mediante escrituras o credenciales de producción.
